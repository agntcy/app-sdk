## Type changes

These changes only add or tighten types; none of them changes behavior. The fixes above are not repeated here.

1. `pyproject.toml`: mypy `strict = true` for `src`, `tests` and `examples`, with no per-module overrides. Also `mypy_path = "src:stubs"`, `explicit_package_bases = true`, and `types-psutil` and `types-docker` as dev dependencies.
2. `src/agntcy_app_sdk/py.typed`: PEP 561 marker shipped in the wheel, so users' type checkers read the SDK's annotations.
3. `stubs/`: local `.pyi` stubs for the untyped dependencies `agntcy.dir_sdk` (client, config, models), `identityservice` (SDK and the Starlette auth middleware) and `ioa_observe.sdk.tracing`. They cover only the API this repo uses.
4. `Taskfile.yaml`: a `task typecheck` command (`mypy --no-incremental`).
5. CI: a `pytypecheck` job in `reusable-python-build-and-test.yaml`, enabled from `build-and-test.yaml`.
6. `.pre-commit-config.yaml`: a local mypy hook that runs the same configuration.
7. `transport/base.py`: full signatures on every abstract transport method. `gather_stream`, `request_stream` and `start_streaming_conversation` are typed `AsyncIterator[Message]`, and `from_config` / `from_client` use a `TypeVar` for the returned class.
8. `transport/nats/transport.py`: annotations on every method and callback (`Msg`, `NATS`, `asyncio.Queue[Message]`), with the client typed `NATS | None`.
9. `transport/slim/common.py`: `cast`s for the `slim_bindings` variants that UniFFI adds at import time (`IdentityProviderConfig.*`, `IdentityVerifierConfig.*`, `JwtKeyData.DATA`). The shared-connection helper returns `tuple[Service, App, int]`.
10. `transport/slim/transport.py`: `_SlimReceiveError` and `_SlimSessionError` aliases for the error variants mypy can't see, `cast(asyncio.BaseEventLoop, ...)` for `uniffi_set_event_loop`, and typed attributes (`Callable[..., Awaitable[Any]] | None` callback, `int | None` connection id).
11. `transport/slim/session_manager.py`: annotations on every method, with `Session` and `App` types.
12. `transport/streamable_http/`: annotations on the transport stubs, and a typed `__aexit__` (`type[BaseException] | None`, `TracebackType | None`) in `models.py`.
13. `semantic/message.py`: typed constructor (`headers: dict[str, str] | None`, `status_code: int | None`) and `dict[str, Any]` for the serialized form.
14. `semantic/mcp/` and `semantic/fast_mcp/`: annotations on the protocol, client, client factory and handler methods. The memory streams are typed with `SessionMessage | Exception`, the bound servers are `MCPServer | None` / `FastMCP | None`, and the ASGI callables use `MutableMapping[str, Any]`.
15. `semantic/a2a/client/`: annotations on the factory, the config dataclasses and the experimental client. The producers registered with a2a's `ClientFactory` match its `TransportProducer` signature and return `ClientTransport`, and `create()` returns `Client`.
16. `semantic/a2a/server/`: annotations on the JSON-RPC, SRPC, patterns and card-bootstrap servers. `_server_task: asyncio.Task[None] | None`, `context_builder: CallContextBuilder | None` on SRPC, and `cast`s where a2a returns a wider type than the SDK sends.
17. `semantic/a2a/utils.py`: typed `get_agent_identifier` and `_extract_topic` (`str | None`), and the SLIM binding and scheme sets as `frozenset`s.
18. `app_sessions.py`: annotations on `AppContainer` and `AppSession` (`signal.Signals`, `asyncio.Task[None]`, `-> None` on lifecycle methods).
19. `factory.py`: `A2AAccessor`, `MCPAccessor` and `FastMCPAccessor` `Protocol`s for the client-factory accessors, and `Type[BaseClientFactory]` in the accessor builder.
20. `common/tracing.py`: an `_Instrumentor` `Protocol` and a `cast` at the `importlib` call for the dynamically loaded instrumentors.
21. `common/logging_config.py`: `get_logger` returns a typed `structlog.stdlib.BoundLogger` via `structlog.stdlib.get_logger`.
22. `directory/base.py` and `directory/dir/agent_directory.py`: full signatures on the directory interface and the AGNTCY directory client (`str | None`, `list[Any]`, `bool`, `RecordVisibility`).
23. `examples/mcp/`: annotations on the Docker and host monitor servers and the monitoring client, with `dict[str, Any]` results and explicit narrowing of Docker and MCP data.
24. `tests/unit/`: every test function and helper annotated (`-> None`, fixtures, fakes). `Any` is used only for deliberately wrong calls, catch-all fakes and JSON payloads, and `MagicMock` values are left as `Any`.
25. `tests/e2e/conftest.py`: `Protocol`s for the server-launcher fixtures (`RunA2AServer`, `RunCardBootstrapServer`, `RunMCPServer`, `RunA2ASlimRpcServer`), and annotations on every e2e test.
26. `tests/server/` and `tests/guide_examples/`: annotations on the test servers, the agent executor and the guide examples, with `TYPE_CHECKING` imports for types used only in annotations.
